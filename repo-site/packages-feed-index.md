# trusttunnel feed — `__ARCH__`

The signed package feed for the `__ARCH__` architecture in the OpenWrt
`__TREE__` release tree. The package manager of the tree reads this
directory. apk (OpenWrt 25.12+) fetches `packages.adb`. opkg (22.03–
24.10) appends `/Packages.gz` to the feed URL. The feed keeps the newest
`__KEEP__` releases, because the published site has a hard 1 GB limit.
Older versions stay on their GitHub releases.
