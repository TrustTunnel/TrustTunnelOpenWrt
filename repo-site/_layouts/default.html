--- --- {% comment %} The branded page shell of the site. Jekyll uses this file before the theme layout of the same name (GitHub Pages renders the site with jekyll-theme-primer). The header below therefore appears on every page that names no other layout. That includes the homepage, which jekyll-readme-index renders from README.md with the default layout. The generated index pages (releases/, releases//, the per-feed pages) name it in their front matter. The structural levels in between use the redirect layout. The differences from the theme layout are deliberate: - The header carries the TrustTunnel logo, a label that names this site, and links to the GitHub repository, the releases and the website of the organization. - The theme footer ("This site is open source. Improve this page") is gone. Jekyll builds its link from the source path of the page. That path exists only for the homepage (repo-site/README.md). The generated index pages have no such file in the repository, so the footer would point at nothing on most pages. - The site-title heading of the theme is gone. The header already names the site. The theme would print the repository name as a second, redundant title above every page. - The brand styles live in the {% include head-custom.html %}
